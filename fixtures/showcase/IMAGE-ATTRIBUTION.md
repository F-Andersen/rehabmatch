# Портрети спеціалістів (showcase)

- **Тип:** синтетичні ілюстративні портрети, згенеровані локально скриптом `server/scripts/generate-showcase-portraits.ts` (бібліотека `sharp`, SVG-композиція).
- **Особи:** не є фотографіями реальних людей; профілі в БД також синтетичні.
- **Ліцензія:** вихідний код RehabMatch MVP; зображення можна використовувати разом із проєктом для навчальної демонстрації.
- **Шлях у UI:** `/images/specialists/sc-001.webp` … `sc-048.webp`.
- **Повторна генерація:** `npm run showcase:portraits -w server` (детерміновані кольори за індексом).

Для захисту можна замінити файли на фотореалістичні AI-портрети вигаданих осіб з окремим реєстром ліцензій; поточний набір відповідає вимозі локального завантажуваного зображення без placeholder-тексту.
