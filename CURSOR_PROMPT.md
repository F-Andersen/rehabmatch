**Основні вимоги**: React + Vite + TypeScript, Node.js + Express + TypeScript, Prisma + PostgreSQL, Docker Compose, Tailwind; три ролі (patient, specialist, admin), реальна auth, каталог і фільтри, профілі, пошук, керування вагами критеріїв (AHP pairwise + CR та окремий direct-weights WSM режим), обчислення й збереження рекомендацій та explanation, відгуки і модерація, легкі заявки на консультацію зі статусом (НЕ підтверджене бронювання), адмінпанель, responsive UI. Використовуй синтетичні fixture дані, ніяких реальних персональних або медичних даних. Власний AHP/WSM алгоритм має бути математично перевірним і протестованим. Жодних нейромереж, Python, LLM API або зовнішніх платних інтеграцій.

**Порядок виконання**: спочатку виконай лише Milestone 0+1 (узгодження структури, bootstrap проєкту, БД та seed, healthcheck), запусти реальні перевірки й повідом про результат. Далі зупинись і попроси підтвердження на наступний milestone. Надалі не переписуй готові модулі без потреби, роби малі завершені ітерації.

**Після кожного milestone** дай короткий звіт українською: створені файли, функції, успішні/провалені команди, скріншоти або спосіб візуальної перевірки, ризики та наступний етап. Якщо запуск неможливий у середовищі — не стверджуй, що все працює; напиши відсутні перевірки. `npm run build`, `npm run typecheck`, тести, міграції та seed — вимоги до готовності, не декоративні задачі.

**Вимога до якості**: нічого не залишай як фейкові кнопки або hardcoded рекомендації. Якщо потрібне розширення оригінального ТЗ — зафіксуй його в `docs/10-SOURCE-MAPPING-AND-DECISIONS.md`. Продукт призначений лише для демонстрації алгоритмічного ранжування, не для медичних рішень.
