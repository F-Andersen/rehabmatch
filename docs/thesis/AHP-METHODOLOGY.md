# AHP + WSM у RehabMatch

## Режими

- **AHP_PAIRWISE** — 10 незалежних порівнянь п’яти критеріїв; геометричне середнє по стовпцях; нормалізація ваг (сума = 1); λmax, CI, CR; поріг **CR ≤ 0.10**.
- **DIRECT_WSM** — прямі оцінки важливості 1–9 з нормалізацією у ваги (baseline WSM, не класичний AHP).

## Критерії (фіксовані ключі)

`EXPERIENCE`, `PRICE`, `RATING`, `LOCATION`, `FORMAT` — не змінюються алгоритмом; admin може лише оновлювати опис/активність без деактивації обов’язкової п’ятірки.

## Scoring

Після hard filters кожен кандидат нормалізується в [0,1] по критеріях; підсумковий score = Σ(weightᵢ × normalizedᵢ). Tie-break: score → `ratingCount` → `specialistId` (лексикографічно).

## Переваги

Прозорість для користувача (пояснення factors), узгодженість з науковою літературою AHP, можливість відхилити неузгоджені порівняння.

## Обмеження MVP

Немає клінічної валідації; рейтинг — агрегат схвалених відгуків, не доказ ефективності лікування; обмежений набір критеріїв; без геолокаційного routing у реальному часі.

Детальні формули — `docs/04-AHP-ALGORITHM.md` та unit-тести `server/src/algorithms/`.
