# ПРОМПТ ПРОДОВЖЕННЯ (після завершення етапу)

Прочитай актуальні `AGENTS.md`, `docs/IMPLEMENTATION-STATUS.md`, `docs/08-IMPLEMENTATION-PLAN.md` і всі специфікації, релевантні наступному НЕзавершеному milestone. Перевір git diff та фактичний стан коду. Реалізуй лише наступний milestone, не ламаючи попередні. Дотримуйся дизайну з `design/reference/`. Після реалізації виконай потрібні команди, онови status, надай короткий звіт українською з результатами й зупинись перед наступним етапом. Не створюй заглушки під виглядом робочих можливостей. Якщо бракує даних — сформулюй конкретний блокер і обмежене рішення, а не довільно змінюй концепцію.
